# NITRO LINK 🏎️

משחק מירוצים תלת־ממדי אונליין שרץ ישר בדפדפן – בלי התקנות ובלי שרת.

## מצבי משחק

1. **מסלול מכשולים – 30 שלבים** מקל לקשה: רמפות, קפיצות, בלוקים מחליקים, מטאטאים, פטישים, פלטפורמות נעות ואיים שצריך לכוון אליהם באוויר. בכל כמה שלבים נפתח סוג מכשול חדש.
2. **מחוברים בשרשרת – 20 שלבים** לשני שחקנים ומעלה: כל המכוניות קשורות בשרשרת, פותחים שערים בכפתורים ועולים במעלית. מי שנופל נשאר תלוי, ואם כולם באוויר – נופלים יחד.

שלב נפתח אחרי שמסיימים את הקודם. לכל שלב נשמר **שיא אישי**, ומקבלים **XP** על סיום שלב חדש ועל שבירת שיא של עצמכם.

## חשבון וטבלת שיאים

בתפריט הראשי לוחצים **התחברות / הרשמה** ובוחרים שם משתמש וסיסמה. בלי חשבון אפשר לשחק כאורח, אבל ההתקדמות לא נשמרת.
**טבלת השיאים** מחולקת לשניים: מסלול יחיד (שם, שלב ו‑XP) ומסלול לשניים (שמות שני השחקנים, השלב והזמן).

כברירת מחדל הכול נשמר **במכשיר** (בדפדפן), והטבלה מתמזגת בין חברים שמשחקים יחד באותו חדר.
כדי לקבל טבלה עולמית אחת וכניסה לחשבון מכל מכשיר צריך לחבר Firebase (חינם, כחמש דקות):

1. ב‑[Firebase Console](https://console.firebase.google.com/) יוצרים פרויקט.
2. **Build → Authentication → Sign-in method** – מפעילים **Email/Password**.
3. **Build → Realtime Database → Create database**, ובלשונית **Rules** מדביקים:

```json
{
  "rules": {
    "users": { "$uid": { ".read": "auth != null && auth.uid == $uid", ".write": "auth != null && auth.uid == $uid" } },
    "lb": {
      ".read": true,
      "race": { "$uid": { ".write": "auth != null && auth.uid == $uid" } },
      "chain": { "$key": { ".write": "auth != null && $key.contains(auth.uid)" } }
    },
    "rooms": { "$code": { ".read": true, ".write": "$code.length == 4" } }
  }
}
```

4. **Project settings → General → Your apps → Web app** – מעתיקים את `apiKey` ואת `databaseURL` לקובץ `js/config.js`.

החלק `rooms` משמש כ**חיבור גיבוי**: כשהחיבור הישיר בין שני מחשבים נחסם (נתבים מסוימים, רשת סלולרית), המשחק מעביר את הנתונים דרך Firebase במקום. בלי החלק הזה חברים ברשתות כאלה לא יצליחו להצטרף.

(המשחק שומר ב‑Firebase כתובת מייל פיקטיבית שנגזרת משם המשתמש; הסיסמה מנוהלת על ידי Firebase ולא נשמרת במשחק.)

## איך משחקים עם חברים

1. שחקן אחד לוחץ **צור חדר** ומקבל קוד בן 4 תווים.
2. לוחצים **העתק קישור** ושולחים לחברים (או שהם מקלידים את הקוד ולוחצים **הצטרף**).
3. המארח בוחר מצב משחק ולוחץ **התחל משחק**. עד 8 שחקנים בחדר.

החיבור הוא ישיר בין הדפדפנים (WebRTC דרך [PeerJS](https://peerjs.com/)), ולכן האתר יכול להיות סטטי לגמרי.
הלשונית של המארח צריכה להישאר פתוחה כל זמן המשחק.

## העלאה ל‑GitHub Pages

1. צרו מאגר (repository) חדש ב‑GitHub והעלו אליו את כל הקבצים שבתיקייה הזו.
2. במאגר: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, בחרו את הענף `main` ואת התיקייה `/ (root)` ושמרו.
3. אחרי דקה‑שתיים המשחק יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.

## הרצה מקומית

**ב‑Windows:** לחיצה כפולה על `start.bat` – הוא מפעיל שרת מקומי קטן ופותח את המשחק בדפדפן (צריך Python מותקן). משאירים את החלון השחור פתוח בזמן המשחק.

פתיחה כפולה של `index.html` לא תעבוד, כי הדפדפן חוסם טעינת קוד מקבצים מקומיים. אפשר גם להפעיל שרת ידנית:

```bash
python -m http.server 8765
```

ואז לפתוח את `http://localhost:8765`.

## מה חדש

- **מירוץ חברים** – 30 מפות פתוחות (קצרות / בינוניות / ארוכות) עם תמונת תצוגה מקדימה בלובי. המירוץ נגמר כשכולם סיימו או 45 שניות אחרי הראשון, ואז מוצג פודיום לשלושת הראשונים. מי שסיים צופה בשאר (רווח / A מחליף שחקן).
- **קרב מכוניות** – 4 זירות. נוגחים בחברים ומעיפים אותם מהזירה; לכל אחד 3 חיים, והאחרון שנשאר מנצח (או אחרי 4 דקות).
- שני המצבים האלה, וגם השרשרת, דורשים חדר עם לפחות שני שחקנים.
- **דרך הגביעים והחנות** – גביעים 🏆 מרוויחים בשלבים, ובמירוץ חברים ובקרב: 3 / 2 / 1 גביעים לשלושת הראשונים ו‑4 מטבעות למנצח (שלב חדש = מספר השלב, שלב חוזר = שליש ממנו), ומטבעות 🪙 בכל משחק. בדרך הגביעים אוספים טפטים, צבעי גרדיאנט ונוצות; בחנות קונים פריטים נוספים. הכול נלבש במוסך ונשמר בחשבון.
- **שלבים** – אחרי שלב 10 הקושי עולה מהר יותר, נוספו קטעים חדשים (גבשושיות, שיקאן, ירידות, זיגזג ועוד), ולכל שלב ערכת צבעים, שמיים, ריצוף וקישוטים משלו.
- **נהיגה** – במהירות נמוכה ההיגוי מסובב את המכונית במקום. מד ניטרו ברור ליד מד המהירות.
- **סאונד** – מוזיקת מירוצים (אפשר לכבות בתפריט העצירה), וצליל המנוע נשמע רק בזמן ניטרו.
- **שלט** – כל שלט מחובר נתמך, כולל שלטי נינטנדו (מקל או חיצים להיגוי).
- **תת־קטגוריות במירוץ חברים** – רגיל (30 המפות), ארוך ומפותל, קרח (אחיזה נמוכה), וקארט: מסלול מעגלי של 3 הקפות עם תיבות הפתעה (טורבו, מגן, גל הדף, כתם שמן, ברק). שימוש בחפץ: חץ מטה (או `F`), או `LB` בשלט. נסיעה אחורה במקלדת היא רק עם `S`.
- **אורחים** – ההתקדמות, הגביעים, המטבעות והפריטים נשמרים בדפדפן גם בלי הרשמה, ועוברים לחשבון כשנרשמים.
- **טבלת שיאים** – נוספו טבלת גביעים וטבלת זמנים לכל שלב.
- **אימוג'ים וצופר** – מקשים `1`–`5` (או הכפתורים בצד המסך) מקפיצים אימוג'י מעל המכונית, ו‑`Tab` (או לחיצה על מקל בשלט) מצפצף.
- **חנות** – נוספו גלגלים, אפקטי שובל וצופרים.
- **בוטים** – המארח יכול להוסיף בלובי עד שלושה בוטים ולבחור לכל אחד רמת קושי 1–7. הם משחקים בכל המצבים (מסלול, מירוץ חברים, קרב ושרשרת) ונחשבים כשחקנים לצורך "לפחות שני שחקנים". במשחק מול בוטים בלבד לא מקבלים גביעים ומטבעות במירוץ חברים ובקרב.
- **אנימציות** – נוקאאוט בקרב (פיצוץ, גל הדף, רעידת מסך וכרזת K.O), וחגיגת ניצחון עם קונפטי ומצלמה שמקיפה את המנצח.
- **מיני גיימס** – מצב חדש עם ארבע קטגוריות: **תופסת** (זירה ענקית, התופסים מהירים יותר ומדביקים בנגיעה), **תפוס את הכתר** (נקודה לכל שנייה עם הכתר, נגיעה חוטפת אותו, 60 נקודות לניצחון), **הרצפה נעלמת** (האריחים נופלים בזה אחר זה, האחרון שנשאר מנצח) ו**קרח** (מירוצי הקרח שעברו לכאן ממירוץ החברים).
- **רכבי מם בחנות** – נקניקייה, בננה, ארגז קרטון, גבינה, ברווז ענק, אסלה ונעל. נבחרים במוסך תחת "דגם".
- **תצוגה מקדימה** – לחיצה על פריט בחנות, בדרך הגביעים או על פריט נעול במוסך מציגה אותו על המכונית בלי לקנות.
- **מראה לפי משתמש** – המראה של המכונית נשמר בחשבון (או בדפדפן אצל אורחים) ונטען אוטומטית בהתחברות מכל מכשיר.
